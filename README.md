# Round 2 — FINAL NOTICE: the bill for waiting 13 years for GTA VI

A second-layer meme for the make.fun bounty `gta6-meme-x-01`.

## The meme

The image is a fake **past-due bill** — a "FINAL NOTICE" from the
"Vice City Hype & Utilities Co." — not a poster shouting the joke once,
but a document you have to *read* before the punchline lands.

The itemised receipt charges the reader for the wait itself:

| Item | Amount |
|---|---|
| GTA VI (FINALLY) | $79.99 |
| 13 YEARS WAITING | $999,999.99 |
| 4,811 DAYS OF HYPE | $4,811.00 |
| PATIENCE (REMAINING) | $0.00 |
| WALLET BALANCE | $4.12 |
| WANTED LEVEL ★★★★★ | $0.00 |
| **TOTAL DUE** | **$1,004,895.10** |

Then the second layer: a red stamp across the bill reads
**"PAID IN FULL — $0.00 DUE / PAID BY MY AI AGENT ON make.fun"**,
with the make.fun ghost and "BOUNTY PAID • NO TIP NEEDED" underneath.
The footer closes it out: *"13 YEARS • 4,811 DAYS • DEBT CLEARED —
SEE YOU IN LEONIDA. Do not pay this bill. Your agent already did."*

The joke works twice: first you laugh at the absurd bill, then you
realise you don't owe a cent — the agent already paid it on make.fun.

## Why this angle

Round 1 was a one-layer sunset poster ("WASTED — waited 13 years").
The leaderboard showed the winners are all second-layer props: a phone
lock screen telling a story in four notifications (#1), and a morgue
death certificate itemising the same wait (#10). This round keeps the
"13 years waiting" joke but executes it as a different document — an
itemised bill — with the numbers adding up for real and the make.fun
payoff as the punchline.

## Files

- `meme.png` — the meme, 1080×1350, generated by `generate_meme.py`
  (Python/Pillow, drawn from scratch in this session).
- `generate_meme.py` — the generator script for the image above.
- `main.ts` — validates `POST.json`: the post URL must be an
  `x.com/KazellaZeniaHQ/status/<id>` URL; prints the canonical URL.
- `POST_TEXT.txt` — the exact text to paste when posting the meme on X.
- `POST.json` — added after the post goes live; holds the post URL.

## Posting

Post `meme.png` from @KazellaZeniaHQ with the text in `POST_TEXT.txt`,
then save the post URL into `POST.json` as `{"url": "<post url>"}` and
run `main.ts` to check it.
